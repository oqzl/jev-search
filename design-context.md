# Design context — Jev Search

## Product identity
Jev Search. Jev is TypeSafe's model for selecting sources and ranking results; Search1API supplies the search engines. Use TypeSafe's official pink icon for the search results header and browser icons. Keep the builder attribution in the footer, not in the wordmark or page title. The page title and subtitle should communicate both source selection and ranking.

The homepage has no separate header or logo image. It uses a compact left-aligned wordmark, subtitle and search surface rather than a centered hero. Three plain-text example requests remain directly below the search field and read like recent/suggested searches rather than marketing cards. The footer keeps two icon-and-word links (Showcase, Community) above the rule and one credit line below it. The search results page retains its compact navigation header.

## Users
Developers and AI-curious people, many of them following TypeSafe's Jev. They arrive from a post or a link, type one question, and judge the product in the first ten seconds by whether the results look right. Desktop first, phone second.

## Brand personality
Precise · candid · quiet. It shows its judgment instead of talking about it, and it never pretends to answer ("no generated answers").

## Aesthetic direction
The visual language is a compact modern search workbench: flat neutral surfaces, hairline borders, restrained shadows and no pill-heavy chrome. Corners stay at 8px or below. Light remains the default, with TypeSafe pink #e551ba used as an accent rather than a large filled surface. Search result links keep the familiar blue-before / purple-after convention. Typography uses the system UI stack throughout, with tighter tracking for the wordmark and headline. Motion exists only for feedback and continuity.

## Design principles
1. The interface fragment is the copy: show the chips lighting, show the percentages, write one sentence.
2. Say Jev by name where it acts: picks where to look, ranks what comes back.
3. Nothing decorative that a user could mistake for a control.
4. One credit line, once.
